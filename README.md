# garden_cosmos · 가든코스모스

`gcosm`은 Ubuntu 터미널에서 Cosmos SDK 계열 CLI를 탐색하고 실행하는 Go TUI입니다.
CLI 도움말로 descriptor를 만들고, 기존 TOML 설정을 읽으며, 실행 결과를 정렬·컬러링합니다.
현재 버전은 **0.7.2**입니다.

## 시작

Go 1.23 이상과 분석할 Cosmos CLI가 필요합니다. 권장 터미널 크기는 120×40 이상입니다.

```sh
go build -o bin/gcosm ./cmd/gcosm
./bin/gcosm --doctor
./bin/gcosm --cli /absolute/path/to/xplad
```

인자 없이 실행하면 마지막 CLI 설정을 불러옵니다. 저장된 CLI 설정이 없으면 도움말을 출력하고 종료합니다. 첫 실행은 `--cli`로 경로를 지정하세요.
경로 입력은 파일 자동완성을 지원합니다. 기본 home은 CLI의 `--home` 도움말 기본값에서 찾으며,
직접 지정하려면 다음과 같이 실행합니다.

```sh
./bin/gcosm --cli /absolute/path/to/xplad --home /path/to/existing/.xpla
# TUI 없이 descriptor만 생성/검증
./bin/gcosm --cli /absolute/path/to/xplad --analyze
# 캐시 무시하고 다시 분석
./bin/gcosm --analyze --refresh
```

`jq`, `batcat`은 선택 도구입니다. 없으면 해당 기능을 열 때 Ubuntu 설치 명령을 안내합니다.
기본 TUI와 JSON 정렬·컬러링은 이들 없이도 동작하며, 앱에서 sudo를 자동 실행하지 않습니다.

```sh
sudo apt update
sudo apt install jq bat
```

## 시작 배너와 종료 요약

TUI를 시작하기 전에 제공된 `docs/icon_px.sh`의 컬러 아트를 출력하고, 꽃 아래 중앙에 **버전만** 표시합니다.
아트는 바이너리에 내장되어 실행 위치와 무관하게 표시되며, 원본 스크립트를 실행하거나 수정하지 않습니다.
출력 직후 대기 없이 TUI로 전환하고 종료하면 원래 터미널 화면으로 돌아와 배너 아래에 요약을 덧붙입니다.
`NO_COLOR` 또는 `TERM=dumb`, 출력 리다이렉션에서는 색상 제어 코드를 제외합니다.
`--version`, `--doctor`, `--analyze`처럼 TUI를 열지 않는 모드의 출력은 그대로 유지합니다.

종료 요약에는 이번 세션의 **명령 종류 수 / 총 실행 횟수 / 종료 코드 0 / 오류 / 취소·시간 초과**와
명령별 실행 횟수를 표시합니다. 종류는 CLI 경로와 하위 명령 경로를 기준으로 하며 인자 값은 저장·출력하지 않습니다.
캡처 및 대화형 실행을 포함하고, 확인창 취소·자동 도움말 분석/버전 조회·jq·클립보드 같은 보조 호출은 제외합니다.
프로세스 시작 실패는 별도로 표시합니다. 종료 코드 0은 트랜잭션의 블록 포함 성공을 의미하지 않습니다.
요약은 정상 종료와 TUI 오류 반환 시 출력하며 강제 종료(SIGKILL)에서는 출력할 수 없습니다.

## 조작

- 시작 포커스: 명령 검색창 (CLI 미설정 시에는 설정창 먼저 표시).
- 검색창에서 Enter: 검색 결과 첫 명령의 인자 입력 폼을 엽니다. 결과가 없으면 그대로 유지합니다.
- 검색창에서 ↑: 검색 결과의 마지막 항목을 선택하고 명령 목록으로 이동. ↓: 현재 선택을 유지한 채 명령 목록으로 이동. 목록에서 문자 입력: 검색창으로 이동하며 그 문자를 기존 검색어에 입력.
- 마우스: 명령·버튼·입력창 선택, 결과 스크롤.
- Tab: 검색 → 명령 → 결과. Shift+Tab: 검색 → 결과 → 명령의 역순 이동. 명령에서 Enter: 입력 폼. 폼 안에서는 Tab/Shift+Tab으로 필드 이동. Esc: 대화창 닫기 / 명령 목록으로 이동.
- F1: 현재 CLI 경로·체인 home 확인/변경 및 현재 CLI 재분석.
- F2: 최근 주소·해시와 주소록. 최신순 검색·선택·별명/메모 편집.
- Enter: 선택한 명령의 입력 폼 열기.
- F5: 도움말 재분석.
- F6: `client.toml`, `config.toml`, `app.toml` 읽기 결과 및 분석 경고.
- F7: 폼에서 입력 검증·실행 미리보기 후 결과를 TUI에 캡처. stdout/stderr, 종료 코드, 소요 시간을 구분.
- F8: 폼에서 입력 검증·실행 미리보기 후 원래 터미널에서 대화형 실행. 비밀번호·Ledger 확인 등에 사용. 종료 후 Enter를 누르면 통합 출력을 결과 창에서 확인할 수 있습니다. 실행 직전 `대화형 실행 시작: 전체 명령줄`, 종료 후 `대화형 실행 종료: 종료 코드 또는 오류`를 출력합니다.
- F9 결과쿼리: JSON은 jq로, 일반 텍스트는 grep 확장 정규식(`grep -E`)으로 조회합니다. 텍스트 검색에는 stderr도 포함되며 빈 검색어는 전체 내용을 표시합니다. 전용 창의 위쪽에 원본 출력, 중앙에 쿼리 입력창, 아래쪽에 쿼리 결과를 표시합니다. 양쪽 출력 영역에는 각각 스크롤바가 표시됩니다. 입력창에서 Enter로 적용하며 창을 유지합니다. 매번 원본에 적용하며 JSON은 `.`, 텍스트는 빈 검색어로 전체 내용을 다시 볼 수 있습니다. 창을 닫아도 기존 결과창 내용은 유지됩니다. Tab/Shift+Tab으로 원본·입력창·결과 이동, 방향키·PageUp/PageDown·마우스 휠로 스크롤, F9(돌아가기) 또는 Esc로 닫습니다. 검색어는 명령줄이 아닌 패턴으로만 전달합니다. 텍스트 예: `ERROR|WARN`, `^height:`. 예: `.balances[] | {denom, amount}`.
- F10: 앱 종료. 실행 중인 작업은 취소 처리가 끝난 뒤 종료합니다.
- F3: 입력값/최근 항목/표시 결과 복사. F4: 입력 칸에 붙여넣기. 우클릭: 클립보드 메뉴.
- **F12: 토큰 계산기. 다른 대화창이나 캡처 실행 중에도 열 수 있음.**
- Ctrl+C: 분석/캡처 실행 중에는 취소, 대기 중에는 앱 종료.

명령을 선택하고 Enter를 누르면 전용 입력 폼으로 이동합니다.
예: `query bank balances` → 필수 address에 주소 입력 → `사용: output` 체크 후 `json` 선택 → F7.
마우스로 하단 실행 버튼을 누르거나 Tab으로 폼 끝의 버튼에 이동할 수도 있습니다.

- `<arg>`와 `[arg]` 위치 인자는 모두 필수(*)입니다. `[flags]`와 `[command]`는 위치 인자에서 제외합니다.
- 입력 폼은 위치 인자 → 필수 플래그 → 선택 플래그 순서로 표시하며, 각 그룹 안에서는 기존 순서를 유지합니다.
- 플래그는 기본적으로 선택이며, 설명에 `(required)`/`[required]`가 명시된 플래그는 필수로 처리합니다.
- 선택 인자·플래그는 `사용` 체크박스로 활성화합니다. 해제하면 값을 보존하지만 명령에 전달하지 않습니다.
- 위치 인자는 모두 입력해야 실행할 수 있습니다.
- bool은 true/false, 도움말의 `(a|b|c)`는 드롭다운, 정수는 숫자 입력란을 제공합니다.
- 알려진 정수 범위, 유한한 실수, duration, 주소 형식, coins, gas, node URL을 검증합니다.
  체인 계정 존재·주소 체크섬·체인별 추가 제약은 CLI가 확인합니다. 불명확한 문자열에는 임의의 제약을 추가하지 않습니다.
- 주소/닉네임 자동완성과 home/file/dir 플래그 경로 자동완성을 지원합니다.
- F2 북마크 또는 F12 계산기 결과는 **폼에서 마지막으로 선택한 활성 입력 칸**에 넣습니다.
- 필드 하나가 인자 하나이므로 공백이 있는 값을 따옴표로 감쌀 필요가 없습니다. variadic 인자는 공백으로 구분합니다.
- 검증 실패 및 실행 확인창 취소는 입력을 보존합니다. 입력 폼에서 Esc를 누르면 목록으로 돌아갑니다. 같은 명령을 다시 열면 세션 내 입력 초안을 복원합니다. 위치 인자 초안은 디스크에 저장하지 않습니다.

일반 플래그 전체의 값과 선택 상태를 실행 확정 시 저장합니다. 다른 명령에도 같은 이름의 플래그가 있으면 복원하며, 세션의 오래된 초안보다 최근 사용한 플래그 값을 우선합니다.
저장 범위는 CLI 실제 경로 + 분석한 home입니다. 비밀번호·시드·개인키·토큰 등 민감한 플래그는 저장하지 않습니다. 확인창에서 취소한 값은 공통 설정을 바꾸지 않습니다.
선택한 home은 폼의 home 필드에 기본 활성화되며, 사용자가 변경하거나 해제할 수 있습니다.

## 최근 항목과 주소록

명령 폼에서 입력할 칸을 활성화하고 선택한 뒤 **F2**를 누르세요.
최근 입력·출력한 주소/해시가 최신순으로 보이며, Enter 또는 `입력` 버튼으로 해당 칸에 바로 넣습니다.
선택한 항목은 최근 사용 시각을 갱신하여 위로 올라갑니다. 입력란 자동완성도 같은 최신순을 사용합니다.

- F2 또는 `최근`/`주소록` 버튼: 두 목록 전환.
- Tab/Shift+Tab: 검색창과 목록 전환. 주소·해시·별명·메모로 검색.
- Ctrl+N 또는 `주소 등록`: 주소와 별명을 입력해 주소록에 보관.
- Ctrl+E 또는 `별명/편집`: 선택 항목의 별명·메모·값 수정.
- Del 또는 `삭제`: 선택한 항목을 최근 목록/주소록에서 삭제.
- Esc: 입력 폼으로 복귀.

주소에 별명을 붙이면 주소록에 나타납니다. 별명을 비우면 최근 목록에만 남습니다.
기존 `bookmarks.json`의 별명 있는 주소도 그대로 주소록에서 사용할 수 있습니다.
같은 값은 중복 생성하지 않고, 다시 입력되거나 출력되어도 별명과 메모를 유지합니다.

폼에서 바뀐 활성 필드의 주소/해시는 실행 미리보기, F2 열기, 폼을 나갈 때와 정상 종료 시 저장합니다.
변하지 않은 기본값을 단순히 열어보는 것만으로는 최근 순서를 바꾸지 않습니다.
캡처 실행의 stdout/stderr에서도 수집하지만, 기존과 같이 키 관리 등 민감한 명령과
비밀번호·시드 관련 입력 필드는 제외합니다. 대화형 출력도 결과 창에 표시하지만 비밀번호 입력처럼 터미널 에코가 꺼진 키 입력은 수집하지 않습니다.
목록과 주소록은 현재 `--data-dir`의 `bookmarks.json`에 저장되어 재실행 후에도 유지됩니다.
주소 형식을 검사하지만 체크섬·체인 소속까지 검증하는 주소록은 아닙니다.

## 클립보드 복사·붙여넣기

입력 칸에서 **F3**로 전체 값을 복사하고 **F4**로 커서 위치에 붙여넣습니다. 마우스 오른쪽 클릭으로도 클립보드 메뉴를 열 수 있습니다.
CLI 설정, 명령 폼, 검색, 주소록 편집, 계산기, 결과쿼리 입력창에서도 사용할 수 있습니다.
붙여넣기는 필드의 숫자 등 입력 제약을 따르며, 명령을 자동 실행하지 않습니다.
단일 줄 입력에서는 끝의 줄바꿈을 제거하고, 여러 줄 JSON은 한 줄로 압축합니다.
그 밖의 여러 줄 텍스트나 제어 문자는 안내 후 거부합니다.

- 최근 목록/주소록: 선택 후 `복사` 버튼 또는 F3. 우클릭 메뉴의 `선택 값 복사`도 사용 가능합니다.
- 결과: 우클릭 메뉴에서 `표시 결과 복사`, `원본 stdout 복사`, `stderr 복사` 중 선택합니다.
  TUI 색상 태그는 복사하지 않으며 원본 stdout/stderr는 CLI가 출력한 원문입니다.
- 입력 칸: `선택 값 복사`는 전체 값, `입력 칸에 붙여넣기`는 커서 위치에 삽입합니다.
  명령 인자 입력 중에는 자동완성 목록이 열려 있어도 붙여넣을 수 있습니다. 터미널의 붙여넣기도 필드 검증을 따릅니다.
- 클립보드 창은 Esc/닫기로 이전 화면과 포커스로 돌아갑니다. Ctrl+C는 기존 취소/종료 동작을 유지합니다.

Wayland에서는 `wl-copy`/`wl-paste`, X11에서는 `xclip`의 CLIPBOARD 선택 영역을 사용합니다.
Wayland 도구가 없고 X11 DISPLAY와 xclip이 있으면 X11 도구를 사용합니다.
두 도구가 없으면 KDE 세션에서는 `qdbus6` 또는 `qdbus`로 Klipper의 복사·붙여넣기를 사용합니다.
Klipper 경로는 Qt 도구가 덧붙이는 출력 줄바꿈 하나만 제거하며 원래 내용의 줄바꿈은 보존합니다.
클립보드는 사용자가 복사·붙여넣기를 요청할 때만 접근하고 내용은 별도 파일로 기록하지 않습니다.
한 번에 최대 4 MiB, 도구 실행은 최대 2초로 제한합니다.

```sh
# Wayland
sudo apt install wl-clipboard
# X11 / XWayland
sudo apt install xclip
./bin/gcosm --doctor
```

도구 미설치 또는 데스크톱 세션 접근 실패 시 앱에서 안내합니다. 자동 sudo 설치는 하지 않습니다.
SSH/헤드리스 환경에서는 로컬 PC 클립보드를 직접 제어하지 않으므로 터미널 자체 복사·붙여넣기를 사용하세요.
터미널의 Ctrl+Shift+C / Ctrl+Shift+V 등 기존 기능도 계속 사용할 수 있습니다.
터미널이 우클릭을 자체 메뉴로 처리하는 경우 F3/F4를 사용하세요. 앱이 우클릭 이벤트를 받으면 앱의 클립보드 메뉴가 열립니다.

명령 폼 하단에는 검증 후 실행·대화형 실행·돌아가기 버튼 세 개를 한 줄로 고정합니다. 대괄호는 각 버튼의 양 끝에 표시합니다.
Tab은 상단 복사 → 체크박스·활성 입력칸 → 검증 후 실행 → 대화형 실행 → 돌아가기 → 상단 복사 순서로 순환합니다. Shift+Tab은 역순으로 이동합니다. F6으로 필드와 하단 버튼 사이를 바로 전환할 수도 있습니다.

구현 참고: [wl-clipboard](https://github.com/bugaevc/wl-clipboard), [xclip](https://github.com/astrand/xclip).

## 정확한 토큰 계산

계산기의 마지막 입력·토큰 선택·변환 방식·계산 결과는 앱 재시작 후에도 복원됩니다. 이전 선택이 없으면 `ibc/` denom을 제외한 첫 번째 토큰을 선택합니다. IBC 토큰만 있으면 직접 입력으로 시작하며, 이전에 선택한 IBC 토큰은 그대로 복원합니다.
읽기 전용 최종 결과의 **결과 복사**와 **인자에 삽입**은 최소 단위라면 `1000000000000000000axpla`, 표시 단위라면 `1 XPLA`처럼 단위까지 포함합니다.

F12 계산기는 `+`, `-`, `*`, `/`, 괄호, 음수, `1e18` 표기를 지원합니다.
계산은 `math/big.Rat`으로 수행하여 float64 정밀도 손실이 없습니다.

- 사칙연산만: `0.1 + 0.2` → `0.3`.
- 표시 단위 → 최소 단위: decimal 18에서 `1.000000000000000001` → `1000000000000000001`.
- 최소 단위 → 표시 단위: decimal 6에서 `1234567` → `1.234567`.
- 최소 단위 변환 결과가 정수가 아니면 경고하고 인자 삽입을 막습니다. 자동 반올림하지 않습니다.
- `1/3`은 정확한 분수와 별도로 표시된 근삿값을 보여줍니다. 근삿값은 인자에 삽입하지 않습니다.
- 심볼·최소 단위 denom·decimal(0~36)을 저장할 수 있습니다. 기본 예시는 ATOM/uatom 6, XPLA/axpla 18입니다.
- `인자에 삽입`으로 정확한 결과를 명령 폼의 선택한 입력 칸에 넣습니다. denom은 필요할 때 직접 붙입니다.

decimal은 사용자가 선택한 토큰 설정이며 체인에서 자동 검증하지 않습니다.
서로 다른 토큰의 수량도 수식에 넣어 계산할 수 있지만 가격/환율을 자동 조회하거나 적용하지 않습니다.
대화형 CLI에 터미널을 넘긴 동안에는 TUI 계산기를 사용할 수 없고, CLI 종료 후 다시 사용할 수 있습니다.

## 분석과 저장

시작 시 CLI의 `version`(실패하면 `--version`), 실제 경로, SHA-256을 비교합니다.
버전이나 바이너리가 바뀌면 `--help`를 재귀적으로 읽어 descriptor를 교체합니다.
도움말 조회는 1회당 8초, 깊이 12, 최대 2,000 명령으로 제한하며 실패한 하위 명령은 경고로 남깁니다.
`help`, `completion` 자체는 탐색에서 제외합니다. 실제 실행 직전에도 바이너리 해시가 바뀌면 재분석을 요구합니다.

분석 중에는 `init`·트랜잭션·설정 쓰기 명령을 실행하지 않습니다. 기존 home의 설정만 읽고,
설정이 없으면 만들지 않습니다. CLI가 변하지 않아도 시작/재분석 때 TOML을 다시 읽습니다.
명령 의미·필수 위치 인자·위험도를 완벽히 추론하는 도구는 아니므로 원본 help도 함께 표시합니다.

기본 저장 위치는 `${XDG_DATA_HOME:-$HOME/.local/share}/garden_cosmos`입니다.
`--data-dir`로 체인별 별도 공간을 만들 수 있습니다. 한 데이터 폴더는 동시에 한 프로세스만 사용합니다.

- `profile.json`: 선택한 CLI 경로와 home.
- `descriptor.json`: 버전·해시·명령 트리·플래그·설정 스냅샷·경고.
- `bookmarks.json`: 자동 수집한 주소/해시와 사용자가 붙인 닉네임·메모.
- `common-flags.json`: CLI/home별 공통 플래그 값과 활성 상태.
- `tokens.json`: 계산기 토큰 preset.
- `calculator.json`: 마지막 계산기 입력, 선택, 계산 결과.

저장 파일은 0600 권한으로 원자적으로 교체합니다. 설정 파일 읽기는 JSON5를 지원하며 출력은 표준 JSON입니다.
CLI 결과는 외부 프로토콜의 표준 JSON으로 판별하여 정렬합니다.
원본 실행 출력/인자 이력은 디스크에 자동 저장하지 않습니다.
`keys`, `export`, `init`, `genesis` 명령의 출력은 자동 캐시에 넣지 않습니다.
주소·해시 탐지는 문자열 형식 기반이므로 주소 체크섬이나 실제 체인 소속을 보증하지 않습니다.
사용자 지정 명령에서 비밀을 출력하는 경우도 있을 수 있으므로 북마크에 개인키·시드를 저장하지 마세요.
자동 캐시는 1,000개로 제한하고 가장 오래 사용하지 않은 항목부터 제거합니다. 주소록과 메모·별명이 있는 항목은 별도로 보존합니다.

## 실행 특성과 현재 범위

캡처 모드는 stdin 없이 최대 2분 실행하고 stdout/stderr 각각 4 MiB까지만 표시합니다.
Ctrl+C/시간 초과 시 자식 프로세스 그룹을 중단합니다. 이미 전송된 트랜잭션은 취소되지 않습니다.
종료 코드 0은 블록 포함이나 체인 실행 성공을 보증하지 않으므로 결과의 `code`, `txhash` 등을 확인해야 합니다.
장시간 실행 및 비밀번호/장치 입력은 F8을 사용하세요. F8 출력은 자동 수집하지 않습니다.

현재는 표준적인 영어 Cobra 도움말을 대상으로 합니다. 별도 플러그인·비표준/번역 help에는 추가 어댑터가 필요할 수 있습니다.
설정 편집, 온라인 토큰 메타데이터/가격 조회, 트랜잭션 포함 추적, 복수 RPC 프로필, 명령 즐겨찾기,
출력 간 diff는 후속 기능입니다. 위치 인자는 필수로 처리하며 체인별 추가 검증은 CLI의 오류를 확인합니다.

상단에는 usage와 입력값을 반영한 전체 명령줄이 표시됩니다. 명령줄을 클릭하면 복사됩니다.

하단에는 F11을 제외한 F1~F12를 같은 폭으로 고정 표시합니다. 현재 사용할 수 없는 기능은 라벨을 비워 둡니다. F10 종료는 항상 표시합니다. 키 번호는 어두운 배경의 흰색, 기능 라벨은 청록색 배경의 검은색으로 표시합니다. F3은 복사, F4는 붙여넣기이며 하단 기능키 영역을 클릭해도 실행됩니다.

### 0.6.0 대화형 결과 캡처

Ubuntu의 `script`(util-linux)로 PTY를 유지하며 출력을 화면에 실시간 전달하고 최대 4 MiB를 메모리에 보관합니다. 원문 출력 파일은 만들지 않습니다. 도구가 없으면 `sudo apt install util-linux`를 안내합니다.
종료 후 Enter로 결과 창에 복귀하며, F3 복사·F9 결과쿼리를 사용할 수 있습니다. stdout/stderr는 합쳐집니다. 프롬프트나 에코된 입력이 섞이면 JSON으로 인식되지 않을 수 있습니다.
ANSI 색상·제어 코드는 결과 창에서 제거하므로, 커서를 이동하는 전체 화면 프로그램의 화면을 그대로 재현하지는 않습니다. CLI가 화면에 표시한 내용은 결과에도 포함되지만, 에코가 꺼진 비밀번호 키 입력 자체는 수집하지 않습니다. 기존 민감 명령의 주소/해시 캐시 제외 규칙은 유지됩니다.
대화형 실행 경로와 결과 처리 기능을 추가하여 minor 버전을 올렸습니다.

### 최근 주소·해시 선택

주소 또는 해시 입력칸은 빈 상태에서도 최근순 자동완성 목록을 표시합니다. ↑/↓로 이동하고 Enter 또는 마우스로 선택하면 값이 입력됩니다. 주소 칸에는 주소, 해시 칸에는 해시만 표시하며, 별명과 메모로도 검색할 수 있습니다. 입력칸을 벗어나면 입력한 주소·해시를 저장하고, 선택한 값은 최신순으로 올립니다.

F2에서 캐시 전체를 확인하고 `별명/고정`으로 별명을 붙이면 자동 정리(일반 캐시 1,000개 제한)에서 제외됩니다. 주소뿐 아니라 해시도 고정할 수 있습니다. 별명·메모를 지우면 고정을 해제하며, 명시적인 삭제는 가능합니다. 민감한 입력과 키 생성·내보내기 출력은 기존처럼 수집하지 않습니다.

`keys list`의 JSON 배열에서는 공개 `address` 필드만 캐시에 수집합니다. 키 이름·pubkey·기타 필드는 수집하지 않으며, 키 생성·내보내기 등 다른 키 관리 명령은 계속 제외합니다.

Usage의 `--type=[height|hash]`는 위치 인자가 아닌 필수 플래그로 표시하고, `height`/`hash` 선택 목록을 제공합니다. 뒤의 `[height|hash]`는 별도의 위치 인자 입력칸 하나로 유지합니다. 저장된 descriptor의 Usage에도 적용되어 재분석 없이 폼에 반영됩니다.

공통 플래그 값은 현재 명령의 형식과 허용값을 통과할 때만 복원합니다. 허용되지 않는 값은 현재 명령의 초안 또는 기본값으로 대체하며, 드롭다운 선택지에 추가하지 않습니다.

명령 목록에서는 `query`, `tx`, `tx bank`처럼 하위 명령 안내를 위한 상위 그룹을 숨깁니다. 검색해도 그룹 자체는 표시하지 않으며, `tx bank send` 등 실제 하위 명령은 계속 검색할 수 있습니다. 저장된 descriptor에도 적용되므로 재분석이 필요하지 않습니다.

주소·해시 자동완성은 `값 · 별명`으로 표시하며 실제 입력에는 값만 넣습니다. 일반 항목은 청회색 배경과 밝은 회색 글자로, 선택 항목은 밝은 배경과 어두운 글자로 표시합니다.
